# LexPrism

面向律师的三个 Skill：文本生成、文本审阅、股权与交易结构图生成。文本支持争议解决与证据工作、非诉与风险管理、客户服务与业务创新；通过专家反馈改进方法，不绑定某个测试问题或法域。

当前文本技能版本：`0.5.0-shared-project`，2026-09-15。生成与审阅在同一项目的两个对话协作，律师启动对话，技能直接读取共享文稿、审阅意见与工作记录；生图技能保持 `0.2.0-clean-focused` 不变。本地文件版本工具已有行为测试，千问办公／目标宿主实际运行和法律专业效果仍待验证。

## 三个技能怎么用

| 技能 | 职责 | 输入／输出 |
| --- | --- | --- |
| [lexprism：文本生成](skills/lexprism/SKILL.md) | 研究、起草、生成合同审查等工作成果，按意见修订 | 请求与材料 → 核验草稿视图、纯净展示视图两个同版本文件 |
| [lexprism-review：文本审阅](skills/lexprism-review/SKILL.md) | 在另一对话检查证据、覆盖、表达及双版一致性 | 读取项目送审版本 → 单独写入意见与版本判定 |
| [drawio-diagram：生图](skills/drawio-diagram/SKILL.md) | 保持现有股权与交易结构图能力 | 沿用现有输入与可编辑图形输出 |

生成对话 → 提交本地双文件快照 → 审阅对话读取并写回意见 → 生成侧读取意见、修订并提交新版本 → 复审。WORK.md 汇总版本、意见入口与下一步；律师无需搬运内容。无阻断缺陷且必要检查完成时停止循环；机器审阅通过与律师确认分别记录。写入文件本身不会唤醒下一对话。

项目级指令与非 Git 文稿版本管理见[项目设计](docs/2026-09-15-项目协作与文稿版本设计.md)及[操作说明](docs/项目协作操作说明.md)。[PROJECT.md 模板](templates/legal-project/PROJECT.md)协调角色，[AGENTS.md 模板](templates/legal-project/AGENTS.md)提供项目入口，本地程序负责成对快照、基线冲突检查、独立审阅记录与 WORK.md 更新。

两份文本技能均可在指导不足时主动查找专业范文，提炼方法、结构与文风，再依既有标准核验。境内八家律所、办公室偏好和上市尽调参考范围见[专业参考学习](skills/lexprism/references/reference-learning.md)。

独立导入包：[文本生成 0.5.0](dist/lexprism-0.5.0-shared-project.zip)、[文本审阅 0.5.0](dist/lexprism-review-0.5.0-shared-project.zip)、[生图 0.2.0](dist/drawio-diagram-0.2.0-clean-focused.zip)。[项目协作完整包 0.5.1](dist/lexprism-project-0.5.1-project-bundle.zip)统一包含三个技能、项目指令、版本工具、绘图工作台及模板、绘图辅助脚本和操作说明。0.5.1 修正完整包漏含生图的问题，各技能自身版本与生图内容保持不变，旧包保留。

只导入 skill 不等于安装项目运行层；目标宿主须能读取同一目录并执行配套工具。绘图工作台使用在线嵌入编辑器，完整包不包含离线 draw.io 引擎。`dist/`不进入版本库。

共同文本标准以 `skills/lexprism/references/` 为维护源，审阅目录对应文件为同步副本；审阅专用流程维护于 `skills/lexprism-review/references/review-protocol.md`。运行 `python scripts/build_text_skills.py` 同步并打包；`--check` 只检查副本一致性与包内引用。不要单独修改审阅侧共同标准副本。

法源分流采用[国别与任务类型选源引导](skills/lexprism/references/mcp-routing.md)，依据 2026-09-11 MCP 接入说明细化 15 项服务。推荐起点不限制模型自主调度；可根据实际或潜在缺口直接补网络搜索、组合或改用其他可用 MCP。仅给定材料、不联网及本地隐私边界仍生效；已配置不等于已验证。

- “代表乙方审核这份合同”：自动加载合同审查流程，覆盖《合同审查要点》0—30 项，提供条款定位、风险和修改建议。
- “切换为引用对照版／纯净版／同时输出两版”：首次完整交付默认两版，后续沿用选择；可继续要求缩短、调整语气或只改某段。纯净版保留必要引注和实质风险。
- “把这份补充法律资料融入报告”：按原始出处及已确认等级处理，自动定位相关章节、核对支持或冲突关系、局部修订并记录变化；仅在出处或类别不明时标待分级。
- 所有实质法律交付末尾加入风险提示及免责说明；不保证风险消除，合同正文的配套提示放在交付说明中。

以上文件输入与版本保存依赖宿主实际文件能力。客户材料应通过具备文件能力的宿主提供，或在授权范围内将必要文本放入当前请求。

千问办公是当前优先运行环境。它负责模型、对话、文件和工具执行；本地目录维护技能、可移植数据约定、评测材料以及今后需要的MCP封装。GUI与自建Agent运行服务不在本阶段范围内。

## 千问办公连接器

法律数据 MCP 一律在千问办公中维护和启用；本仓库不保存可导入 MCP 配置、连接器凭据、本地 MCP 转发器或本地服务器源码。当前接入状态、法源范围和待验证项维护于[海外法律数据接入评估](docs/海外法律数据接入评估.md)。即使连接器已启用，仍须在具体任务中核验原文、版本/效力和定位；“仅给定材料”任务不得开启外部检索。

原始参考材料留在`律师提示词/`。实际客户材料与带敏感信息的评测存入`private/`，运行记录放入`runs/`，这两个目录不进入版本库。团队分享技能包前需复核它只包含可分享的技能方法与辅助资源。
