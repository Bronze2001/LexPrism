# LexPrism

面向律师的法律 Agent／Skill 包：约70%侧重非诉与风险管理，约30%侧重争议解决与证据工作。通过持续专家反馈改进研究、分析、文书与复核流程，不绑定某一个测试问题或法域。

当前版本：`0.1.0-framework`，2026-09-08。已完成框架、技能初稿与开发计划；数据库连接、程序化核验和千问办公真实运行尚待实施／验证。

## 从这里开始

- [Agent框架](docs/Agent框架.md)：模块、流程、证据记录和专家反馈闭环。
- [开发计划](docs/开发计划.md)：分阶段任务、依赖与验收条件。
- [法律流程图工作台](tools/drawio/README.md)：本地开箱即用的流程图与架构图编辑器（`tools/drawio/index.html`），内置股权穿透、并购交割与证据链实务模板。
- [法律流程图与架构图规范](skills/lexprism/references/diagrams.md)：非诉与诉讼业务中的图表设计标准与律所专业配色规范。
- [海外法律数据接入评估](docs/海外法律数据接入评估.md)：官方MCP／API、适用范围和接入路线。
- [千问办公部署与联调](docs/千问办公部署与联调.md)：取得权限后的实际操作与验证。
- [LexPrism技能入口](skills/lexprism/SKILL.md)：一个可移植入口，按任务加载工作流参考。
- [专家评测](evals/README.md)：持续追加案例和反馈，不把测试答案当通用知识。

本地已生成[Skill ZIP初稿](dist/lexprism-0.1.0-framework.zip)，包含入口与六份参考，可用于取得权限后的导入测试；`dist/`不进入版本库。已通过技能格式校验、5份JSON解析、29处本地文档链接检查与ZIP逐文件一致性检查，未做千问办公运行验证。

千问办公是当前优先运行环境。它负责模型、对话、文件和工具执行；本地目录维护技能、可移植数据约定、评测材料以及今后需要的MCP封装。GUI与自建Agent运行服务不在本阶段范围内。

`config/providers.json`是接入研究记录，不是可直接导入的MCP配置。无真实凭据，也不表示服务已连接。`config/qwenwork-courtlistener.example.json`仅提供官方地址的配置示例，认证和账号访问仍需验证。

原始参考材料留在`律师提示词/`。实际客户材料与带敏感信息的评测存入`private/`，运行记录放入`runs/`，这两个目录不进入版本库。团队分享技能包前需复核它只包含可分享的技能方法与辅助资源。
