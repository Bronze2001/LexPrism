# LexPrism

面向律师的法律 Agent／Skill 包：约70%侧重非诉与风险管理，约30%侧重争议解决与证据工作。通过持续专家反馈改进研究、分析、文书与复核流程，不绑定某一个测试问题或法域。

当前技能版本：`0.2.1-source-routing`，2026-09-08。已补充合同审查、输出视图切换、个人法律资料增量修订及文末风险／免责说明；这些是技能工作规则，千问办公真实运行与法律专业效果仍待验证。

## 本次新增用法

法源分流：仅需中国内地法且允许检索时使用北大法宝，不启动海外法源检索；涉外或多法域问题分别判断，其他路由待 MCP 封装完成后逐步填充。规则集中维护于 [法律研究流程](skills/lexprism/references/research.md)，此处规则不表示对应工具已接入。

- “代表乙方审核这份合同”：自动加载合同审查流程，覆盖《合同审查要点》0—30 项，提供条款定位、风险和修改建议。
- “切换为引用对照版／纯净版／同时输出两版”：首次完整交付默认两版，后续沿用选择；可继续要求缩短、调整语气或只改某段。纯净版保留必要引注和实质风险。
- “把这份补充法律资料融入报告”：按原始出处及已确认等级处理，自动定位相关章节、核对支持或冲突关系、局部修订并记录变化；未配置完整等级时标待分级。
- 所有实质法律交付末尾加入风险提示及免责说明；不保证风险消除，合同正文的配套提示放在交付说明中。

以上文件输入与版本保存依赖宿主实际文件能力。本机 `qwen_chat.py` 仍是单次文本问答客户端，可按需读取技能参考，但不负责上传／解析客户 DOCX、持久化文稿或提供界面切换按钮。客户材料应通过具备文件能力的宿主提供，或在授权范围内将必要文本放入当前请求。

千问办公是当前优先运行环境。它负责模型、对话、文件和工具执行；本地目录维护技能、可移植数据约定、评测材料以及今后需要的MCP封装。GUI与自建Agent运行服务不在本阶段范围内。

`config/providers.json`是接入研究记录，不是可直接导入的MCP配置。无真实凭据，也不表示服务已连接。`config/qwenwork-courtlistener.example.json`仅提供官方地址的配置示例，认证和账号访问仍需验证。

## 本机 Qwen 3.8-Max 直接问答（北大法宝 MCP）

用于先验证模型、Skill 和真实法律数据工具的最小链路。`scripts/qwen_chat.py`调用百炼的 OpenAI 兼容 Chat Completions API，并在本机连接已配置的北大法宝 Streamable HTTP MCP。它会从真实 MCP 取得工具定义、交给 Qwen 选择、执行模型返回的函数调用，再把实际结果回传模型；不启用代码解释器。除入口`SKILL.md`外，预载`research.md`和`data-and-tools.md`，其余参考由模型通过本地只读工具 `read_skill_reference` 按需取得；该工具仅接受技能目录内列出的参考文件名。

当前默认连接五项首轮法律研究服务：法规语义检索、法规关键词、法条关键词、案例语义检索与引文校验。工具名和参数以每次 MCP 的真实发现结果为准，不能把检索列表或摘要当成法条全文。

1. 复制`.env.example`为本机`.env`，填写`DASHSCOPE_API_KEY`和实际的百炼 Workspace ID；`.env`已被Git忽略。
2. 安装依赖：`python -m pip install -r requirements.txt`。
3. 查看真实发现的北大法宝工具：`python scripts/qwen_chat.py --list-tools`。
4. 先验证本地设置（不消耗模型额度，也不访问网络）：`python scripts/qwen_chat.py --dry-run`。
5. 发送研究请求：`python scripts/qwen_chat.py "检索现行法律依据，说明数据出境安全评估的适用门槛和待核实项。"`。

公网搜索默认关闭。因为“仅给定材料”任务不应新增外部来源，且中国法律的版本、效力与正文应优先经北大法宝或官方来源核对。仅在委托允许外部研究、且确有需要补充实时或公开背景时，使用：`python scripts/qwen_chat.py --web-search on "……"`。联网搜索结果同样不是已核对的法律原文，仍须区分来源类型和定位。

百炼的实际地址和 Workspace ID 以账号所在地域为准。此脚本使用`qwen3.8-max`模型 ID；密钥不写入脚本、运行输出或版本库。

原始参考材料留在`律师提示词/`。实际客户材料与带敏感信息的评测存入`private/`，运行记录放入`runs/`，这两个目录不进入版本库。团队分享技能包前需复核它只包含可分享的技能方法与辅助资源。
