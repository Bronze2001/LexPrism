# 法律研究

## 形成可检索的问题

围绕法律问题拆解主体、行为、地域、时间、法律关系、监管机关／法院层级、争议与交付目标。根据必要程度识别前置条件、例外和跨法域连接点。以问题树组织研究，不机械按“法条／案例／文章”组织答案。

检索计划写明每个问题拟查何种来源、为何需要、哪些覆盖仍不确定。来源模式为仅给定材料时，只在批准材料内工作；否则按实际工具能力和授权范围选择数据库／官方站点。

## 法源分流规则

按“法域＋材料类型＋实际覆盖”选择来源，具体推荐起点见 [mcp-routing.md](mcp-routing.md)。中国内地通常从北大法宝开始；美国判例、联邦规章、立法，欧盟一般法与数据合规，以及英国立法分别有适合的 MCP。合同、尽调、意见等工作可按子问题组合来源，不按文种锁死数据库。

本表系选源建议，不是强制门禁、工具白名单或固定顺序。模型可基于已知或潜在缺口，直接决定网络搜索、调用其他实际可用 MCP 或跳过不适合的首选来源，无需等失败或每次重新确认。原 CN-001 的“仅内地法首选北大法宝”保留为建议；原 CROSS-PENDING 的整类等待规则由细分建议取代。

仅给定材料、不联网及本地隐私限制仍按用户要求执行；自主选择来源不代表可以突破来源范围。工具可用性依真实定义及调用结果判断，记录实际来源、选择原因和缺口；新增依据按既有引用与效力规则核验。

## 来源与效力

按团队《需求与范围》现行标准（2026-09-10 核对）登记来源；这是检索／交付分级，不是法定效力排序：

| 等级 | 团队范围 | 使用边界 |
| --- | --- | --- |
| T1 | 法律法规、判例内相关法官规则语句、政府官网问答、中国政府规范性文件及指导意见 | 分开记录文件类型和具体法律作用；政府问答不等同法律，判例不能仅因句子在结论段就认定其为裁判规则 |
| T2 | 大型国际律所、四大会计师事务所等专业机构的分析文件／文章，包括可确认由同一机构发布的微信公众号文章 | 记录机构、文章及原始依据，不能把分析意见写成法律原文 |
| T3 | 媒体报道及其他缺少权威依据的网站／公众号分析 | 作为背景或检索线索；重大法律结论不能仅凭此下定论 |

T1 优先使用官方中文或英文。对非中英语言的官方材料，检索并记录官方中／英文版本的可得性；仍未取得时，保留母语原文，标明“未取得官方中／英文版本”，自动翻译为中文，并按团队规则将本次使用等级记为 T2、注明语言降级原因。不能将机器英译当官方英文以规避降级；已取得官方中文时不因缺英文降级。原文仍记录为官方来源，不能把等级变化解释为该法规法律效力降低。依法处理材料的本地限制优先，参见 [translation-privacy.md](translation-privacy.md)。

分别记录原始来源属性、团队使用等级、等级调整原因、原文语言、译文类型和具体法律作用。无法确认出处或材料不属于上述类别时标为待分级，不强行塞入 T3。个人提供只是取得渠道，使用同一规则；AI 报告与商业转载需回查原始出处，不按数据库品牌自动获得 T1。补充资料更新见 [supplemental-materials.md](supplemental-materials.md)。

对于法规记录研究基准日、相关版本、施行与废止信息、未纳入综合文本的修订；无法确认时标明未知。历史事实可能需要历史法，不将“最新”一律视为适用版本。

### 在起草前判断依据是否可用

每个决定性法律依据分别记录：**原文取得与逐字对应、基准日版本／效力、对本案主张的支持与适用性**，每项有实际证据或未完成原因。单独的 verified-verbatim 只证明核对到相应原句，不代表其他两项通过；审阅侧也按三项独立复核。

只有旧制定公报而缺现行综合文本时，继续查主管机关修订公告、施行通知、条文沿革、当前办事指引和适用的附属规则，围绕实际引用的条款补查。修订条例的标题、网站导航、仍相同的条号或“官网仍有旧PDF”不能证明条文未变。补查无需固定工具顺序，也不要求穷尽与本案无关的修法。

主站反爬只说明该获取路径失败。足以支撑具体主张的官方材料可按其真实性质使用；不能把官方问答冒充条例逐字原文，也不一律要求取得整部综合文本才可继续。必要的效力或适用性仍不明时，挂起受影响结论，完成其余可支持部分；披露缺口不能使无依据结论变为可通过。

引用纠错同样适用本规则。另一条例的罚款级别、类似机关的期限、相近术语的定义均不自动适用于本案；提出替代结论必须核对相应制度的适用依据。

逐一分开记录成文／签署日、公布日、网页发布日期、施行日与检索日；生效时间优先核对施行条款，不从网页标题或文号推算。旧答复中“正在起草／目前／拟出台”等表述只能说明答复当时状态，引用到当前事项须补查后续进展。数据库“现行有效”字段、报告内的来源编号或自行生成的快照都不能代替原文核验。

### 判断适用范围须读完整规则

在认定某主体“不适用”、某机关“不审批”或某手续“必需”前，除定义条款外，检索同一文件的附则、参照执行、例外、转引和过渡条款，以及直接相关实施规定。只查第二条等定义片段不足以排除适用；缺少全规则时标为未能确定，不能用一般定义覆盖附则特别规定。

把规则拆成“主体＋行为／项目＋地域＋资金或金额＋时间＋例外→法律后果”。规则列出不同主体和行为分支时分别匹配，不能把事业单位等同企业，或把所有境外活动等同境外投资。全国规则、地方示例、窗口意见与经验判断分开，属地未知时地方例只能展示差异，不能成为全国流程中的必经机关或步骤。

涉及身份或资质限制时，以实际行为、权责和资金／货物流向匹配规则，不能仅凭合同名称、账户注册或“咨询／代理／分包”等标签决定适用或豁免。服务商、被服务企业与持牌合作方分别判断；合作方的资格不当然覆盖客户自身行为。将行业机会转为“客户可提供该服务”前，核实客户资质、产品／服务范围及规则承认的具体条件。

相反材料审阅不仅是列出罚则或一般风险，还应主动找可能改变本结论的适用条款、条件和例外。缺少专门 MCP 不等于官方网页不可访问；按 mcp-routing.md 自主补查可用网络或工具，不把可完成的原文核对一律推给律师。

对于案例区分事实、裁判理由、结论及程序阶段；核对法院层级、法域、后续处理和与本案有关的关键要素。较新案例不当然推翻较旧案例；相似主题也不意味着核心要素相同。引用网络只是关系数据，不能自动判断判例仍然有效。

## 检索和验证

### 部门指导意见与规范性文件

涉及中国内地审批、行业监管、地方执行或政府指导要求时，问题树中显式列出需查的部门／地方规范性文件，不只搜索法律、行政法规和法院案例。在北大法宝实际开放能力内组合业务关键词、发文机关、地域和“通知／意见／办法／指引／实施细则／公告／批复／规范性文件”等词检索，已知文号时按文号查原文。

按事项识别中央主管部门、相关联合发文机关及地方实施机关，检查权限、上下级关系和交叉监管。覆盖原文与附件、联合发文、修改／废止决定、清理目录及实施文件；仅当用户授权且现有工具允许时，补查相应政府官网或公报，不预设新增 API 已接通。

逐份记录标题、文号、发文机关、适用地域／主体、发布日期、生效和失效信息、文件性质、关键段落及与上位规则的关系。“红头”外观不证明权威或效力，“指导意见”名称也不自动意味着强制义务；查明适用内容后再写具体要求。未找到、数据库未覆盖、无权限与效力不明分别记录。

### 原文取得与核验

1. 依问题树检索并记录查询词、筛选条件、提供方、检索时间和覆盖限制。组合原语术语、同义表达和排除条件；必要时补查例外与反向材料。
2. 从命中记录取得可访问原文并保存具体位置。只取得摘要时标`search_snippet`；只取得供应商报告时标`provider_generated_report`，不冒充原始全文。
3. 对候选规则核查适用前提及支持／相反片段。采用专业分析时说明它对原始来源的解释性质，必要时回查原文。
4. 根据关键问题是否得到支持、反向依据是否核查及工具预算决定继续还是结束。没有材料支持时写缺口；不以结果条数证明研究穷尽。

工具失败与检索无结果是不同状态。权限不足、限流、网络错误和空结果分别记载；实际无法调用的数据库不可出现在“已检索数据库”中。相同失败只做有限重试，保留已完成部分。

数据库覆盖较弱时，优先取得会改变核心结论的官方文件、现行办事说明及可回查译本；可用可靠专业分析解释方向，按具体主张限定用途，不强求每条均有两家来源或全文母语复核。同一文章的官网、数据库镜像与转载算一个来源，先查作者和内容来源再判断交叉印证。来源等级、取得程度与结论确定程度分别记录，不能把新闻因涉及法规就升为专业法律意见。

“未见反证”只描述检索结果，不证明现行有效。已发现相关修订但未读到内容时，应查其是否影响所引条款；未能排除影响前，不用旧法确定客户资格、费用或期限。法规名称、文号或主管机关尚未确认的候选线索放待核记录，不用“通称”包装为正式依据。主站获取失败时，可按主张需要使用已获授权的官方其他页面、附件或可信镜像；不无限重试同一路径，也不直接把本可补取的关键材料交给律师。

成篇文书采用的来源如有可下载文件，无论 T1/T2/T3，均在授权和许可范围内下载留档；保留原文件、原始网址、获取时间、版本、保存位置和可得哈希。简短答复在对话保留可回查引注及实际核验范围，不为留档自动创建事项或扫描全部连接器。未提供文件下载能力、下载失败或许可受限时记录具体原因，不能把链接记作已下载。不对客户机密材料默认进行外部上传。

取得响应后先辨别它是目标原文、摘要、登录／反爬页面还是错误页。失败响应不计作有效法源，不进入已核验来源集；确有诊断保留需要时放在清楚标注失败的独立位置。改用其他获授权来源仍按同一核验标准，无法补齐决定性原文就保留受影响结论待核实；不把工具故障转成确定法律答案，也不因一个来源失败停止不受影响部分。

## 交接给分析与写作

指导不足时的范文和方法检索按 [reference-learning.md](reference-learning.md)。八家境内律所及办公室偏好仅用于专业参考选源，不改变本文件的 T1/T2/T3、原文定位、效力和适用性标准；上市尽调公开文书也不因发布渠道而免于核验。

交接问题树、来源、原文片段、候选规则、适用条件、相反依据和缺口。输出模式可为简短答复、检索备忘录或多法域比较。来源目录不替代正文主张的具体引注。

检索内容之后必须有精炼的“检索结论”：直接回答本次问题，列清具体义务／权利、适用前提、执行动作与有依据的时间要求，保留尚未解决的关键条件；不要只重复长篇背景或泛称“应依法合规”。正文、脚注和文末汇总按 [drafting-review.md](drafting-review.md) 统一生成。
