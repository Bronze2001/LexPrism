# 法律文稿审阅执行

读取指定版本的完整文稿、原始任务及对应证据；已有双视图要求时取得完整双文件。普通文件无需初始化，核验说明不足可先在授权材料中定位原文。先完成必要检查面再给整体结论；未做部分明确记录，不把“继续审旧稿”当作新稿复审。

## 四维检查

| 维度 | 实际检查 |
| --- | --- |
| evidence 证据与分析 | 核对引文、转述和原材料对应关系。涉及法律判断时，另确认原文取得范围、基准日效力与本案适用性，按 [research.md](research.md) 查定义、例外、转引／过渡和相反材料；来源目录、逐字一致或已披露不代替适用判断。纯事实校对不扩成法律研究。 |
| coverage 覆盖 | 从原始问题及有效补充要求反查结论，有无漏答、超范围或把未知当不存在；摘要、建议保留正文的前提和期限起点。仅加载适用的业务清单；法律检索报告按 [legal-research-report.md](legal-research-report.md)，样本漏项不成为标准。 |
| prose 文风 | 直接通读纯净文件：答案是否明确，分析是否连贯、结构和篇幅是否适合读者，术语是否清楚，是否残留内部日志，是否保留必要限定和文末说明。共同成品标准见 [drafting-review.md](drafting-review.md)。 |
| views 一致性 | 有双视图时比对版本、事实、结论、条件、金额／期限、建议、引注、未决风险及文末说明；共同正文不能改变含义，必交视图缺件时不得通过。普通文件核对正文与核验说明的对应；未要求双视图时，多视图比对可记不适用，不补造冗余正文。 |

有预览能力时查看页面标题、分页、表格、脚注和截断。无能力时记“可提取文本已检查，页面未核验”；纯文本任务的页面项可说明不适用，但任务要求验证页面或关键内容只能视觉读取时，该必要检查未完成则PENDING。程序比对不代替语义及页面审阅。

受管理项目读取已封存的候选 Word，正式发布将复制该文件。同成果双视图检查实质一致；备忘录与函件等不同成果检查共同事实、前提及行动相容性，不要求正文相同。完整审阅覆盖本版全部成果，按实际范围、页面检查和独立对话来源填写程序模板，不能以结构校验代替实际核验。

## 意见必须有依据

每条问题绑定稳定编号、版本、视图、章节、原句及必要上下文。原句重复时消歧；跨版本重新定位，匹配不唯一就保留待定位，不猜测问题消失。

| kind | basis应说明 |
| --- | --- |
| error 已证实错误 | 原始出处／授权路径、具体位置、相关原句及本案适用理由；纯表达错误引用文稿与明确要求。 |
| unverified 尚未核实 | 哪项证据或判断欠缺、影响哪个结论；不预设确定的替代答案。 |
| preference 表达建议 | 可选调整的阅读收益，不包装成法定义务或阻断缺陷。 |

提出替代法条、金额、期限或实体结论时，新依据接受同等核验。声称“全文没有”前查完整相关材料和同义表达，只读片段就限定已读范围；句子存在与语境适用分开判断。复核生成侧有证据的异议，允许撤回误报并记录理由。

## 报告与复审

普通文件出一份审阅意见：先写所审任务、文件／版本和总体结论，随后给检查范围／依据、问题及解决条件、未完成项、新增证据或学习参考（如有）、律师确认状态。意见较短可直接在对话回复；需要保存时采用可编辑文档或 Markdown，沿用用户格式。已有项目才写 REVIEW.md 并填程序生成的 result.json，字段需要时查 [data-and-tools.md](data-and-tools.md)，不另造第二套审阅状态。

复审同时读取新旧版、完整旧意见及修订回应（核验说明或 RESPONSE.md），核对实际修改、支持证据和影响范围；可复用确未受影响的检查并说明范围。由审阅侧确认解决或撤回误报，保留编号与理由。“已全部修改”、原句消失或旧PASS均不足。

对整体成品给结论时，核销旧问题后仍通读整份纯净稿，检查摘要、分析、结论、行动清单与脚注是否保留相同条件及确定程度。不能仅凭旧问题已处理推定全稿合格。对材料不足的主张，尤其检查正文是否又把“待核线索”升级为客户必须执行的动作；三项证据核验与混合主张的标签按 [research.md](research.md) 和 [legal-research-report.md](legal-research-report.md) 判断。已有阶段记录可辅助定位，不能代替实际检查。

协调完整反馈的目标：补要件与减少未经核实的断言不得相互抵消。检查是否新增事实、承诺、费用或期限，及其在有关函件、备忘录和行动表中的影响。继承阻断问题保留稳定编号，关闭、撤回或降级时写实际证据和理由；不能遗漏旧问题后直接通过。

不修改送审正文后批准自己的改稿。所审文件在审阅期间变化则核对版本后继续，无法固定则明确限制；出现新版本时本轮意见仍只适用于原绑定版本。普通文件保存意见，项目模式由程序封存；质量判定、问题关闭和停止条件统一见 [review-decisions.md](review-decisions.md)。
