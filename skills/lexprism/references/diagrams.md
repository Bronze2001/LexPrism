# 法律流程图与架构图规范 (Legal Diagrams Reference)

本参考为 LexPrism 在非诉与诉讼业务中生成专业图表（股权架构、交易步骤、资金流向、案件事实时间线与证据链）提供设计原则、配色规范与数据交换标准。

---

## 适用场景与业务定位

在法律工作中，“一张图胜过千言万语”。当任务涉及复杂主体关系、多步骤交割或密集时间线证据时，LexPrism 应当主动或按要求提供图表化交付物：

| 业务领域 | 核心图表类型 | 适用场景与核心价值 |
| :--- | :--- | :--- |
| **非诉·公司与证券** | **股权穿透与控制权架构图** | 上市核查、实际控制人认定、员工持股平台 (ESOP) 穿透、红筹/VIE 境外架构重组。 |
| **非诉·并购与投融资** | **交易步骤与交割流程图** | 并购签约、前置审批 (反垄断/行业前置)、共管账户资金划转、工商登记与交割先决条件 (CPs)。 |
| **争议·事实查明** | **案件事实时间线图** | 密集合同履约过程梳理、违约节点确认、不可抗力事件发生时点、诉讼时效起算与催告。 |
| **争议·庭审与举证** | **争点要件与证据链推导树** | 诉讼请求 → 法律构成要件 → 待证事实 → 支撑书证/物证 → 证明力漏洞与对方抗辩反驳。 |

## 律所专业商务视觉与色彩规范

图表必须具备清晰严谨的视觉层级，严禁使用杂乱、刺眼的非标准配色。统一采用以下标准色板：

| 元素分类 | 建议填充色 (`fillColor`) | 边框线条色 (`strokeColor`) | 文字颜色 (`fontColor`) | 适用对象说明 |
| :--- | :--- | :--- | :--- | :--- |
| **核心主体 / 发行公司** | `#1B365D` (经典深海蓝) | `#0B1E38` | `#FFFFFF` (加粗) | 目标公司、拟上市主体、争议焦点当事人。 |
| **控股层 / 重要投资人** | `#2B6CB0` (专业深蓝) | `#1A365D` | `#FFFFFF` | 实控人控股 SPV、领投机构、重要股东。 |
| **下属子公司 / 履约主体** | `#EDF2F7` (素雅浅灰白) | `#CBD5E0` | `#2D3748` | 全资/控股子公司、一般供应商、合同相对方。 |
| **资金通道 / 持股平台** | `#ED8936` (商务橙) / `#D69E2E` | `#C05621` | `#FFFFFF` | 员工持股有限合伙 (ESOP)、银行共管账户 (Escrow)。 |
| **先决条件达成 / 有力证据** | `#2E7D32` (合规深绿) / `#38A169` | `#1B5E20` | `#FFFFFF` | 已经满足的交割条件、已固化的原件书证。 |
| **违约风险 / 争议焦点** | `#E53E3E` (警示红) / `#FFF5F5` | `#9B2C2C` | `#9B2C2C` / 白 | 违约事件节点、未决重大诉讼、对赌回购触发点。 |
| **律师核查备忘 / 待办缺口** | `#FEFCBF` (淡黄便利贴) | `#D69E2E` (虚线) | `#744210` | 经办律师特别提示、未解决的尽调缺口、审计意见。 |

## 图表输出规范与数据格式

LexPrism 可根据读者环境，选择以下两种标准方式交付图表：

### 1. 原生 `.drawio` XML 格式（最推荐）
* **特点**：包含精确的几何坐标、节点对齐、正交连接线与专业样式。
* **交付方式**：
  - 写入项目或输出代码块（标明 `<mxfile>...</mxfile>`）。
  - 用户可直接在 `tools/drawio/index.html` 中通过“⚡ 导入 Agent 代码”直接渲染，并在本地自由拖拽微调节点，按 `Ctrl+S` 保存。
* **必备要素**：
  1. 必须带有明确的**图表主标题**与**法律基准日 (As-Of Date)**。
  2. 股权线必须标明**持股百分比**与**出资形式**。
  3. 交易流向线必须标明**顺序编号**（如“步骤 1”、“步骤 2”）。
  4. 底部或侧边附带 **【经办律师核查备忘卡片】**，提示关键法律风险。

### 2. Mermaid 文本格式（快速预览）
* **特点**：纯文本轻量语法，适合在 Markdown 报告或聊天中快速预览。
* **交付方式**：
  - 使用 ````mermaid` 代码块。
  - 用户可随时复制到 `tools/drawio/index.html` 一键转换为矢量图。

## 门禁体系下的图表审计要求 (Gate Audit)

图表不仅是插图，更是**法律分析的结构化证明**。在 LexPrism 五大门禁（G1~G5）中须遵守：

1. **[G1 受理锁定]**：明确图表的绘制目标（如股权穿透至自然人、或仅梳理直接一层股东；时间线具体起止期间）。
2. **[G3 主张映射]**：
   - 股权图上的每一个百分比，必须与公司章程或工商内档核对一致。
   - 时间线图上的每一个违约日、催告日，必须有相对应的书证支撑编号（如“见证据三”）。
   - 禁止在图表中虚构未核实的关联关系或事实推论。
3. **[G5 审计签发]**：
   - 独立审计员负责核对图表数据与正文文字的一致性，防止“正文写持股60%，图上画成70%”的低级矛盾。
