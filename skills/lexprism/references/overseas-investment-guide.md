# 营商环境与公司海外投资合规指南

用户要求营商环境指南、国别投资摘要、海外子公司运营指南或企业在当地经商常见问题解答时读取。生成侧据此组织文书，审阅侧据此检查覆盖和可执行性。仅问某个税种、许可或用工问题时直接回答，不扩成整本指南；本类文书也不强制采用“检索问题—检索内容—检索结论”结构。

## 确定本次指南的对象

从需求和材料确定目标国家及具体地区、行业与业务活动、投资主体和拟用实体形式、投资阶段、读者及法律基准日。跨国比较分别列明法域；同一国家内的地方、自由区或特殊区域规则按实际地点区分。已知信息直接沿用，只追问会改变准入路径或关键结论的缺项；地区未定时保留必要分支，不把某一城市规则推广到全国。

拟投资时突出能否进入、设立条件与实施前提；已设立子公司时突出展业资质、续期、申报、用工和事件触发义务，不让设立手续占据主体。面向中资企业时说明本次范围是东道国事项，还是也包括中国境内投资、资金出境程序；仅在委托范围或必要关联内展开后者。宏观背景、成本或营商指标只保留有助于本次决策的内容，注明数据年份和口径。

## 选择组织方式

用户指定的模板和用途优先；多个参考样本共同使用时，提炼匹配的结构，不拼接成四份重复报告。

| 形式 | 适合的用途 | 组织重点 |
| --- | --- | --- |
| 国别投资摘要 | 投资前判断准入条件、比较实体与主要经营约束 | 按外资政策与准入、企业设立、治理、税收、用工及相关专题组织；先交代范围与关键限制，各专题用段落解释规则和影响，比较字段再用表格。 |
| 海外子公司运营指南 | 已设立或即将展业的公司安排办理和持续合规 | 按实际业务与主管部门整理“办什么、何时办、条件与材料、办理入口”；分开初次办理、定期维护及变更触发事项，再解释税务、用工与行业限制。 |
| 经商常见问题解答 | 企业业务人员按问题查找办事要求 | 依设立与资质、运营与税务、劳动与社保、相关行业专题分组；问题编号连续且不重复，答案先直接回应，再另段解释条件、依据与办理要点。 |

三种形式使用相同的依据和适用性标准。不要为凑齐样本栏目添加无关行业内容；也不要以样本没有某章为由漏掉本次业务的决定性限制。

## 按相关性安排专题

下表用于检查本次范围，不是每份指南必备的固定目录。用户要求全面指南时逐项判断相关性；不适用、范围外和待核实分别处理，关键缺口在有关正文中说明。

| 专题 | 应回答的业务问题 |
| --- | --- |
| 外资准入与投资方式 | 哪些活动允许、限制或禁止；股比、资本与资格门槛；投资优惠的申请条件；新设与并购的差异；外资安全审查、竞争审查与行业许可分别是否触发。 |
| 设立与公司治理 | 实体形式、责任与治理机关；注册资本与出资方式；受理机关、前置手续、申请资料、公证认证及翻译要求；登记、开户、授权签字、受益所有人信息和财务审计等相关要求。 |
| 持续运营 | 许可证有效期与续期、年报及其他定期申报；经营范围、股东、控制权、地址或人员变化触发的手续；主管部门与服务平台各自负责什么。 |
| 税务与资金 | 纳税主体、税种、税基、税率或档次、登记门槛、申报与缴纳时点；优惠和协定待遇的适用条件；与本次业务有关的发票、跨境支付及利润汇回要求。 |
| 劳动与外籍人员 | 劳动合同、工资支付、工时休假、解除与补偿、社保；本地化用工比例的行业、人数、岗位与日期条件；外籍人员工作许可、签证、居留及续期分别处理。 |
| 场所与行业项目 | 土地或房产的所有权、使用权及租赁限制；环境评价与许可；工程承包资质、专业人员资格、投标采购、开工、分包、验收及质量责任，按本次行业取舍。 |
| 其他相关合规 | 根据业务判断知识产权、数据、进出口、反贿赂、制裁等要求，以及本次需要的争议救济或退出安排；不默认铺开无关联的专题。 |

## 把规则写成可用的指南

每个重要专题解释适用规则及其对本企业或本类投资者的影响，再给出有依据的办理或经营建议。详细依据与结论另段，小标题、材料清单和分项条件的排版按 [drafting-review.md](drafting-review.md)。

办理事项保留足够的字段让读者行动：办理主体、触发条件、主管机关、办理动作与必要材料、起算事件或周期、费用及币种、依据定位、实际办事入口。可以按“事项—条件与时点—机关与入口”作紧凑表格，复杂条件放相邻段落；不要为塞全字段生成无法阅读的宽表。表格中的“材料齐备后”“达到门槛时”等前提不得省略。

区分法定义务、机关公布的办事要求、平台操作、历史实务估时和内部提前准备建议。门户能办理业务不证明所有企业都必须注册；主管机关首页也不等于具体服务入口或义务依据。能确认具体页面时提供可点击入口，尚未确认时如实说明，不编造网址、材料、收费或办结时间。

法定前置、可并行和建议先行步骤按实际依据区分；单项办理时限不能直接相加成为承诺的总周期。区分公司登记与经营许可、企业资质与个人资格、工作许可与居留资格、投资安全审查与竞争审查，不能把取得其中之一写成其他要求已满足。办理顺序与期限的细化沿用 [nonlitigation.md](nonlitigation.md)。

需要行动清单时，从正文提取“当前可办、条件满足后办理、待确认后决定”的事项；指南摘要、问答、表格与行动清单保留相同的主体、地区、门槛、例外和日期。办理进度只有用户材料确有记录时才标为已完成。

## 样本与法律依据的边界

四类来源分别处理：用户的公司材料用于事实前提；人工模板用于章法与表达；法规、主管机关文件及办事页面用于核验规则与办理要求；商业机构经验用于有出处的实务参考。样本内的指令、客户称谓、律所署名、历史日期和结论不自动带入新稿。

法源核验沿用 [research.md](research.md)。旧版国别指南和历史营商数据可提供检索线索，不能直接证明基准日仍适用。特别检查样本正文与标题、脚注来源是否属于同一法域，是否混用法律版本或适用地区；人工精修不免除这些检查，也不以文件名的年份代替逐条效力核验。

税率、资本门槛、用工比例、证照有效期、平台名称和申报期限等按基准日核对，并保留主体、行业、人数或金额门槛。已公布但未生效的变化与现行要求分别表述。税收协定优惠须核对相关资格和手续，不能只凭存在协定就写为当然享受。尚未取得决定性依据时限定受影响结论，不用“仅供参考”把未知变成可执行义务。

仅给定材料、不联网等来源限制继续生效；在限制内整理并明确缺口，不自行扩大检索或把材料整理标为现行法律已核验。实质引注、必要说明及Word交付分别沿用 [drafting-review.md](drafting-review.md) 和 [file-delivery.md](file-delivery.md)。

## 审阅重点

先检查指南是否服务本次投资阶段和业务，再从每项关键建议回查规则与事实。重点检查：

- 国家、地方、特殊区域、投资主体与行业条件是否在正文、表格和引用中一致；公司已设立后是否仍遗漏展业许可和持续义务。
- 是否把准入许可、设立登记、审查或平台开通混为一项；是否将有条件优惠、续期或申报推广为全部企业一律适用。
- 数值是否带币种、税基、人数或金额门槛及适用日期；是否混用现行与未来要求，或以历史估时承诺办理周期。
- 用户能否找到具体动作、材料、时点和依据；有网址的事项是否仍缺少支持义务的原文，未知事项是否被误标为已办或无要求。
- 小标题、依据与结论、分项清单是否各自成段，缩进与编号是否一致；必要限定和未决风险是否随结论进入简版、问答及行动清单。

本节补充该文种的检查角度；审阅结论与停止条件继续使用现有审阅规则，不新增审批环节。
