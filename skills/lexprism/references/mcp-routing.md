# MCP 选源引导

依据项目《MCP接入与部署说明.md》2026-09-11 版本整理。本文提供建议起点和能力线索，不是工具白名单、固定调用顺序或必须完成的检查清单。模型按实际问题、覆盖缺口和当前工具定义自主决定搜索、组合、跳过或替换来源；无需因偏离推荐路线再请求确认。

## 先判断问题，再选择来源

先辨认适用法域和所需材料：成文法、实施规章、规则制定过程、判例、案卷、监管指引、执法决定或已有引注核验。合同审查、尽调或法律意见是工作类型，不各自绑定一个数据库；其中不同问题可使用不同来源。中国主体或中文提问不等于只涉及中国内地法；欧盟法、成员国法、英国法及港澳台法分别判断。

“优先”表示通常适合从这里开始，并非必须先调用或只可调用它。若已知或预计存在地方规则、近期变化、特定法院、全文、附件、语言或历史版本等缺口，可直接搜索官方网站、网页或改用其他实际可用的 MCP；不必等待首选工具报错、不必穷尽全部 MCP。没有实质需要时也不为凑齐来源而增加调用。

来源范围和用户限制仍生效：“仅给定材料／不联网”不新增外部检索；“不上传云／仅本地”依 [translation-privacy.md](translation-privacy.md) 核实处理边界，不把材料发送到不符合要求的服务。本地读取技能参考不等于外部检索。正常允许研究的任务中，网络搜索和可用 MCP 均由模型根据需要自主选择；不存在每次换库或补搜都须批准的门槛。

## 按法域和材料类型选源

下表名称是部署说明里的服务标识，不是可直接调用的函数名。调用前读取宿主暴露的真实工具定义，按参数与结果能力匹配；配置清单只提供发现线索。

| 法域／材料或任务 | 推荐 MCP 起点 | 可自主补充或换源的情形 |
| --- | --- | --- |
| 中国内地法规、合同合规、主体资格及一般义务 | 北大法宝法规／法条服务，细分见下表 | 地方细则、部门附件、最新公告或正文不足时补政府官网、公报或其他能覆盖该问题的可用工具 |
| 中国内地裁判规则、类案、争议风险 | 北大法宝案例语义／关键词及案号识别服务 | 特定法院、后续程序、不利裁判或全文缺口时补法院公开来源及其他可用检索 |
| 中国内地红头文件、审批与监管指导 | 北大法宝法规关键词，配合法条语义／条项检索 | 可直接并行查主管部门和地方官网、附件与清理目录，具体方法见 research.md；不局限于数据库法规目录 |
| 美国判例、诉讼案卷、RECAP 材料 | `pipeworx-us-case-law` | `pipeworx-legal` 可作补充，亦可搜索 CourtListener、法院公开来源；需要时查后续处理，不能把案卷动议当成法院认定 |
| 美国 US Code、联邦／州立法 | `pipeworx-legal` | 补相应官方法典、立法机关或州级原始来源；法案、已通过法律和生效规则分清。不要假定该网关完整覆盖每州 |
| 美国联邦规章、规则制定、Federal Register 通知 | `federal-regulations-mcp-server` | 可用 `pipeworx-legal` 交叉检索，并回查 eCFR／Federal Register；分别核对公布日、生效日、拟议或最终规则和历史版本 |
| 欧盟一般立法、CELEX 定位、修订与综合文本 | `eur-lex-mcp-server` | 原文／附件／语言／沿革不足时查 EUR-Lex／CELLAR 官方页面；必要时用 `pipeworx-legal` 或其他可用来源补线索 |
| 欧盟数据保护、AI Act、DSA、NIS2、EDPB、相关 CJEU 判例／执法决定 | `overview-legal`，法规原文可配合 `eur-lex-mcp-server` | 按实际需要查欧盟法院、欧盟机构及成员国监管机关原始发布；不能因主题相关就默认覆盖所有成员国实施法和判例 |
| 英国立法、修订、地域适用及历史条文 | `lex-uk-legislation` | 可用 `pipeworx-legal` 补线索，回查 legislation.gov.uk；注意英格兰及威尔士、苏格兰、北爱尔兰的适用范围 |
| 英国判例、监管指引；欧盟成员国国内法 | 当前清单无可预设完整覆盖的专用路线 | 按真实工具能力选择可覆盖的 MCP，或直接搜索相应法院、立法及监管官网；英国立法库不等于英国判例库，欧盟法库不等于成员国法库 |
| 香港、澳门、台湾及其他未列法域，如埃及、加拿大 | 不强行指定当前清单中的数据库 | 先找该法域官方法规、法院、政府和监管机构；若其他已暴露 MCP 确能覆盖，则自主采用。香港问题不自动分给内地法规服务 |
| 跨国交易、多法域合规与冲突法问题 | 按子问题组合上述来源 | 分别标注规则法域、连接点及相互作用；出现新法域或监管问题时重新选源，不将某国规则直接用于另一国 |

## 北大法宝九项服务怎么选

| 服务标识 | 适合的输入／用途 | 与其他工具的配合及边界 |
| --- | --- | --- |
| `pkulaw-law-search` | 以事实场景或自然语言寻找相关法条 | 可从口语法律问题开始；结果是否含全文按真实返回判断 |
| `pkulaw-law-keyword` | 已知法规名称、机关、文号、业务关键词 | 适合定位法规和规范性文件；不保证一次关键词检索就穷尽 |
| `pkulaw-law-item-keyword` | 查具体条项内容或条文内关键词 | 获取精确依据，仍核对法域、版本及完整范围 |
| `pkulaw-case-semantic-search` | 按案情、争点和关键法律要素找类案 | 检查事实相似性与决定性要素，不能只凭相似度采纳 |
| `pkulaw-case-keyword` | 已知案名、法院或争点关键词 | 可与语义检索互补、补反向案例，不要求两者每次都调用 |
| `pkulaw-law-recognition` | 从提供的文字中识别法规名称或引用 | 识别是定位线索，不证明该规则现行、真实或支持结论 |
| `pkulaw-case-number-recognition` | 从文字中识别案号 | 识别后按需要取回裁判原文；识别成功不等于案件内容已核实 |
| `pkulaw-citation-validator` | 检查已有引注，辅助一致性复核 | 校验范围以真实工具说明和结果为准，不代替法律适用与语义支持审阅 |
| `pkulaw-doc-link` | 关联文书并辅助形成来源链接 | 有链接不证明已取得全文、位置准确或引用成立 |

不按“九步流水线”调用以上服务。例如已知条文可直接查条项；需要审查文稿引注可从识别和校验入手；纯文字润色无需为了路由额外检索。

## 缺口、换源与停止

由模型综合判断预期覆盖、权威性、时效、全文可得性、定位质量、语言、调用成本与权限，选择最有用的下一步。下列情况可直接补网络搜索或其他可用 MCP：材料只有摘要；法规版本不明；遗漏附件／地方规则；仅找到支持材料但存在反例风险；同类结果相互矛盾；数据快照可能滞后；主问题其实超出该服务范围。

网络搜索也可以是第一步。优先回到适用法域的官方原始发布；专业文章和媒体可提供检索线索，但仍按 research.md 分级和核验。两个网关返回同一上游文书时按原始 ID／URL 去重，不当作两个独立证据相互印证。

调用失败时区分无权限、限流、服务不可用和空结果；调整关键词、换源或结束受影响部分，不无限重试。关键问题及例外已获足够支持时停止；关键缺口未解决则披露，不以调用库数或检索条数证明全面性。

换源只需在工作记录中简记“问题／法域、来源、选择原因、取得范围、未解决缺口”，不把长篇选源过程加入纯净正文。新增法源仍登记、核验并更新引用快照，模型自主选工具不等于跳过证据检查。

## 能力和状态边界

根据 2026-09-11 部署说明，15 项服务是配置记录；其中北大法宝被用户确认正常使用，其余仍需真实任务验证。本轮维护未逐项重测。运行时以宿主当前真实能力为准，不能因为本文列了名字就假造调用；当前清单未列出的工具如已真实暴露且适合任务，也可使用。

CourtListener 官方 MCP、Westlaw／CoCounsel、GovInfo MCP、LexisNexis、vLex、PoliticalData Canada、EULEX.AI 等在该说明中仍为未接入／搁置候选，不预设可调用。若后续宿主确已提供，按真实能力纳入选源，无需等待修改本表。官方网站可访问与某个 MCP 已接入是两回事。Juriscraper 是待封装库，不能当现成 MCP。

后续维护只需补充服务标识、覆盖范围、适合任务、已知缺口及带日期的状态，不建立排他国别白名单。服务部署、凭据变更和安装不由本路由说明自动授权。
