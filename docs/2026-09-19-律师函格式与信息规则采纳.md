## 已采纳的要求

| 要求 | 实际处理 |
| --- | --- |
| 固定段落顺序 | 默认采用标题、致送、委托、事实、依据、引导句、告知点、回复后果、特此函告、两段特别申明、落款的顺序；事实与依据各一段，不新增论证章节 |
| 编号与语言 | 不用编号大／小标题、首先其次再次、加粗段首提示；告知点用1. 2. 3.，通常2—4条，只写要求和有依据的后果；正文以约1000—1700中文字、2页左右为宜 |
| 信息边界 | 只用律师陈述或明确采纳的本案事实；未确认字段用四条下划线占位，不借样本补姓名、车型、VIN、金额、期限、合同条款或署名 |
| 正文引注 | 法条、合同条款在依据段直引，对外函件不加脚注、尾注或来源附录；核验稿保留完整来源、定位和适用条件，同步消除通用脚注规则冲突 |
| 原文核验 | 内地法优先实际可用的北大法宝，全文或服务不足时转官方刊载全文并留痕；合同缺原文时占位并提示以原件核对，政策参考不得变成本案法定标准 |
| 样本与内部储备 | 登记事项在BRIEF记录样本存放位置并标“仅供样式参照”；删去的论证按需留内部储备，未核事项与已核但暂不采用的内容分别记录 |
| 页面与发布 | 实际渲染取得页数、检查首页及余页，能力不足如实记录；沿用版本封存、独立审阅、律师确认、发布，不修改旧封存件 |

## 保留的适用条件

以下处理使结构偏好与本案事实一致，不将模板句式自动变成实体结论：

- “已经构成违约”须有事实、合同义务和适用依据支持；“全部法律后果由对方承担”不作通用默认结论，按实际可支持后果表述。
- “根据委托人提供的资料”与“委托人已承诺真实性”等文字，只在确有资料或承诺时使用；仅有陈述时改写来源，未有承诺时删去承诺句并列待确认。
- 保留两段特别申明的段落功能及用户提供的默认文字，同时按上述事实条件和全文称谓调整，不由声明补正文的事实或依据缺口。
- 已确认的本案信息可以填入；明确要求留空和未确认信息继续占位。单位收函按单位称谓，不机械套“先生／女士”。
- 篇幅与页数是偏好，不通过删除实质条件或压小字号强行达标。其他指定模板或法域仍按本次任务适配。
