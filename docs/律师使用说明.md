# LexPrism 律师使用说明

在已经配置好的工作区内，律师只需操作两个对话窗口、提供材料并确认项目和文件名称。版本保存、审阅意见交接、归档及正式文件生成由后台处理。

## 日常顺序

1. 生成窗口：“根据本项目材料起草文书，并提交审阅。”可以同时给项目名称；如果需要新建项目而你尚未命名，助手会在创建前问一次。可以回复“暂不命名”或继续说明任务，未提供名称时按默认规则建档，交付前再确认名称。已有名称或继续原项目时不重复询问。
2. 审阅窗口：“审阅这个项目当前送审版本。”两个窗口绑定同一事项，不用复制文件或意见。
3. 如需修改，回生成窗口：“按审阅意见修订并提交。”再到审阅窗口说：“复审当前版本。”
4. 通过后回生成窗口：“准备正式交付。”核对链接中的文稿，确认本版、项目名、文件名及交付范围。
5. 成功后得到正式 Word 链接。后台保留原件、旧稿和全部审阅历史；后续实质修改会形成新版本。

窗口由你手动触发；保存文件不会自动启动另一个窗口。决定性事实、立场或材料不足时会集中列出需要补充的信息，已经明确的部分继续处理。

## 文件和状态

草稿与核验说明可随时提供；审阅通过与正式交付分开。送审前固定候选 Word，发布只复制已经审阅和确认的那份文件，不在最后重新改写。默认正式目录只增加一份对外主成果，内部核验和意见留档；需要附件时可一起明确要求。

“已确认，尚未成功发布”表示确认已保存但文件生成失败；稍后说“继续发布”即可接续。已写入但登记失败会单独说明，恢复时不会重复生成。正式文件在本地生成不等于已向客户发送、签署或送达。

简短咨询和少量润色直接答复，不创建成套档案。未配置项目程序的普通独立文件仍可起草和审阅，不能声称已经具有后台登记和发布保障。

## 首次安装

由安装者按[一次性部署说明](一次性部署说明.md)配置共享目录、技能与 MCP。律师日常不运行命令或填写状态表。生成用 lexprism，独立审阅用 lexprism-review；需要股权或交易图时再使用 drawio-diagram。
