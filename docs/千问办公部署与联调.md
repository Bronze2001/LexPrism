# 千问办公部署与联调

安装顺序、技能导入、连接器配置、两个窗口启动语与最小验收已合并到 [一次性部署说明](一次性部署说明.md)，此处保留联调记录要求。

逐项记录：目标环境与日期、技能及程序版本、实际工具名、输入、原始返回、原文定位与版本、错误及人工判断。使用脱敏例子；记录保存在获授权的 private 或 runs 中，不装入分享包。

目录读写、程序执行、Word 生成及页面预览、MCP 工具发现、鉴权和取得全文分别记录。完整业务链须由两个真实窗口执行并保留律师的真实确认；同时验证待补、未确认、新版本、同名冲突和失败恢复。

没有实际记录的项目标“未验证”。本地合成测试与包检查不等于千问端到端或法律质量验收。恢复流程见 [工作区维护与恢复](项目协作操作说明.md)；历史服务快照见 [MCP 接入记录](MCP接入与部署说明.md)。
