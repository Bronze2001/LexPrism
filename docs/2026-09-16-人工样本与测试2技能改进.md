# 人工样本与测试2技能改进

日期：2026-09-16。文本技能及完整项目包版本：0.6.0-evidence-workflow。

## 依据与范围

本轮结合原题“已在香港注册为非香港公司、持有商业登记证的中国公司有何权利义务”、用户提供的人工精修样本，以及千问办公测试2的问题1输出修改技能。样本位置：`测试文档/对照人工精修报告/问题1sample 香港注册外国公司法律检索报告.docx`。

样本本轮按 DOCX 正文与脚注提取阅读；以下是内容、结构和引注分析，不声称完成页面排版审阅。未改样本、原题、测试2原件；保留双文件设计、生图规则、自主学习参考和既有文末说明规则。

## 样本值得采纳的部分

- “检索问题—检索内容—检索结论”建立可复查关系，结论聚焦登记、申报和代表等具体事项。
- 相关原文保留条款层级、条件和部分修订标记，比只有来源名称的列表更方便查验。
- 使用中文标题、统一分层和直接表达，适合作为律师检索报告的起点。

据此增加通用 legal-research-report.md，要求按子问题把原文／转述、本案分析和针对性结论连接起来。已完成登记的题目优先回答登记后的法律地位、持续义务和事件触发事项。篇幅、章节和表格按任务调整，不要求复刻样本全部原文或套用香港题目录。

## 样本需要纠正或独立核验的部分

| 观察 | 依据与改进 |
| --- | --- |
| 原题问权利与义务，样本结论主要列登记和责任 | 原始问题决定覆盖；样本不能授权漏答。也不为凑齐“权利”而把一般商业行为虚构为登记优惠。 |

| 结论对代表停任的总结省略部分触发条件 | 样本摘录第786(1)条包含“停任后没有其他代表登记”，第(4)款例外锚定停任时点；总结不能把任何代表停任一律表述为必须补一人。这是文本内部的条件保留检查，现行适用仍要独立核验。 |
| 周年申报原文摘录有42日，结论该小节未明确该期限 | 新规则检查摘要／结论是否保留执行需要的期限与起点，而非只要求原文区完整。 |

| 将政府问答放“专业文章”分类 | 按真实来源性质分类；样本表头不能改变证据性质或法律效力。 |
| 将1,200至4,800港元描述为费用“增幅” | 公司注册处说明是逾期较高登记费的区间；应区分费用本身与增加额，罚款也另列。 |
| 检索日期留空、结论编号跳号、引注覆盖有限 | 不继承占位信息和编号错误；每处实质引用须可回查。摘录中的2025修订标记也不能单独证明全部材料截至基准日有效。 |

收费性质核对来源：[公司注册处注册非香港公司周年申报表说明](https://www.cr.gov.hk/tc/publications/docs/21-c.pdf)。本轮不是重写该公司的完整法律意见，以上抽查用于修正通用方法，具体案件仍需基准日核验。

## 本轮修改

### 生成

先识别已知身份和当前阶段，按原始问题确定覆盖。对决定性依据分别记录原文对应、基准日效力和本案适用性；不能以 verified-verbatim 代替全部核验。旧公报可作为历史证据，引用到当前问题时须补沿革和适用规则；网站修法标题或“以现行法为准”不能弥补核心缺口。

收到审阅意见可接受修订、附证据提出异议或标待补件。生成者只报告处理，不自行关闭阻断。核验版保留过程，纯净版直接写当前有效的分析与结论，内部编号和旧稿纠错按语移出共同正文。

### 审阅

意见区分 error、unverified、preference，并写 basis。替代条款、金额或期限也要取得相应依据；未取得原文时不能先断言替代答案。声称全文没有某句须确实查相关全文；句子存在与适用本案分开判断。

允许复核生成侧异议、撤回误报。关闭问题须 resolution，说明实际新稿、证据和理由。初审覆盖必要范围，旧稿续查不算新稿复审，已披露不算已解决。共用判定从 manual-bridge.md 拆至 review-decisions.md，手动文件仅保留明确选择的兼容步骤。

### 项目入口和程序

- 完整包根目录新增 AGENTS.md／PROJECT.md 工作区入口，与单个事项的指令区分。
- discover 只读授权根目录及直接 matters 子目录元数据，不自动选客户，也不修改工作索引。选择后按实际事项验证历史。
- check-pair 输出文件哈希和普通Markdown脚注的缺定义／未使用／重复情况；提供唯一明确的共同正文边界才比较正文。范围不明、格式不支持分别报告，不输出法律PASS。
- 新审阅协议2要求意见类型、依据及关闭理由；核心未核实项保持 PENDING，偏好不能阻断，新记录不能降低协议版本。程序只校验字段和状态，无法判断理由是否真实充分。
- 旧事项和旧登记保留兼容；新版程序可直接指向原事项，新建审阅用新版协议，不重写历史。
