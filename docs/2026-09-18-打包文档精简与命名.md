## 文档职责

| 位置 | 调整 |
| --- | --- |
| 仓库 README | 保留产品入口、当前包、技能职责和维护方式；历史说明移至文档索引 |
| 部署包 README | 独立导航页，不再复制律师使用说明 |

| docs/项目协作操作说明.md | 集中存储、恢复和升级；命令及协作协议链接到 Skill |

现有技能协议保持原样；两个独立技能需要各自携带共同参考，由构建同步，不能删掉一侧。工作区 skills 与内嵌独立 ZIP 分别承担直接读取和千问导入，也保留。

## ZIP 命名

新包采用“LexPrism-用途-环境-版本.zip”：三个单项技能分别显示“法律研究与文书”“法律文稿复核”“股权与交易图”，区分“千问导入”和“通用技能”；完整包区分“完整工作区-千问版”和“完整工作区-通用版”。

不再为同一千问完整包同时生成 project、deployment 两个别名。dist/README.md 自动列出当前 8 包以及全部旧 ZIP 的用途，对字节完全相同的包明确标注。旧文件不删除、不移动、不覆盖；既有历史文档中的旧包名保留。

本次更新维护源并重新出包，未覆盖已部署的千问办公测试2工作区或其中事项。已有部署升级时备份后按部署说明更新，保留 matters、output、.lexprism 及私人配置。

## 验证范围

构建验证技能链接、完整包链接、共享参考同步、ZIP 可读性和文件指纹。部署测试从新包解压，检查三个嵌套导入包、MCP 脱敏模板，并运行合成建档、送审、审阅、确认及发布流程。

这些检查不代表千问实际导入、Word 页面或法律质量已经验收；实际环境验收仍按部署说明执行。

本次实际结果：生成 8 个当前包，索引覆盖 55 个历史包；52 项部署与文件流程测试通过，共享参考只读检查通过，8 份现行导航 / 使用文档中的 122 个本地链接可解析。完整包的链接及清单指纹另在构建和部署测试中验证通过。
