# 海外法律数据与北大法宝接入评估

核查日期：2026-09-08。结论来自供应商官方产品页、接口文档、官方仓库和公开许可条款。尚未使用本团队账户鉴权或做端到端调用。存在接口、账号有权使用、千问办公兼容、法律结果可靠，是四个不同问题。

## 1. 选型结论

国内首先接用户确认的北大法宝官方MCP。海外首轮优先试CourtListener官方MCP；为70%的非诉方向，再按实际测试法域选择英国立法或EUR-Lex的官方API封装。已有材料提及律所偏好Lexis，因此商业库优先询问Lexis的API权限。不要为了“海外”一次接齐所有库，也不要只用美国判例库覆盖合规与交易研究。

## 2. 首轮具体接法

### 北大法宝：直连，不重复封装

以[官方完整接入文档](https://mcp.pkulaw.com/docs?doc=mcp-integration)与控制台生成的配置为准，使用Bearer Token。已准备[千问办公配置示例](../config/qwenwork-pkulaw.example.json)，包括法规语义检索、法规关键词、法条关键词、案例语义检索及引用纠错五项。其余服务按实际任务添加，避免一开始暴露大量重复工具。

官方法规关键词服务页面明确存在返回法律列表的能力；列表结果不能自动当成完整法条正文。第一次联调必须记录真实工具名、参数、返回字段和原文取得方式。[服务目录](https://mcp.pkulaw.com/apis)、[法规关键词服务](https://mcp.pkulaw.com/apis/1948588494288982016)

### CourtListener：先官方MCP，后REST备选

官方地址为`https://mcp.courtlistener.com/`。由宿主处理OAuth登录，使用自己的CourtListener账号。先测工具发现、一次检索、一次结果/原文获取以及引文检查；每项是否可用由实际工具清单决定。免费/会员/商业使用的额度和范围需按账户确认，不承诺无限免费。配置见[示例](../config/qwenwork-courtlistener.example.json)。

若千问办公暂不支持该认证流程，可依据[官方REST文档](https://wiki.free.law/c/courtlistener/help/api/rest/v4/rest-api-v47)评估本地MCP适配；不能仅凭协议兼容就宣称直连成功。

### 海外非诉接口：按需求只选一个起步

英国立法API可以取得结构化XML与不同版本，适合建立条款定位与版本记录。欧盟场景用EUR-Lex搜索、Cellar取文档，保留CELEX/资源标识符和语言。美国监管场景再考虑eCFR/GovInfo。三者可以共享Source/Passage输出格式，但不能共享一套未经验证的法域和时效判断。

## 3. 商业数据库应该确认什么

普通律师检索账号不等于API凭据，也不自动授予将全文输入千问模型的权限。准备向现有客户经理询问以下内容即可；本轮未代发邮件或提交申请。

- 当前订阅能否开通API/MCP，开发者账号和沙箱如何取得；是否支持第三方千问办公。
- 授权的国家、数据库、正文、历史版本、引证分析分别有哪些；返回原文还是供应商AI报告。
- 能否把内容用于推理、引用、日志、短期缓存、团队评测；模型供应商/区域/保留期有何条件。
- 鉴权、并发、配额、计费、测试额度与故障处理；标准账号和额外产品的权限边界。

CoCounsel官方接口是“启动研究→查状态→取报告→追问”路线，等待时间和报告形式应纳入流程设计，不能映射成即时全文检索。vLex开发者门户首页存在旧介绍，不能据此否认新目录中的API；反过来，也不能将目录宣传当作已获可用凭据。

## 4. 有内容不代表能直接做抓取MCP

英国国家档案馆Find Case Law提供判决访问，但其针对计算分析和相关AI使用的许可规则需按具体用法确认。个人逐篇阅读与批量计算用途并非同一授权范围，适合先核实再作为产品数据源。[许可说明](https://caselaw.nationalarchives.gov.uk/permissions-and-licensing)、[何时需要许可](https://caselaw.nationalarchives.gov.uk/when-you-need-permission)

CanLII现行条款限制系统化下载及相关自动化访问，因此不列入默认爬虫MCP方案；需要加拿大内容时优先寻找原发布机构或获得许可的渠道。[CanLII条款](https://www.canlii.org/info/terms.html)

这不是对所有法域和数据库的穷尽调查。香港也不会因已有一个测试题就被设为必接专用数据源。新增法域依据后续真实案件/评测需求决定。

## 5. 接入完成的定义

“文档确认”→“账号授权确认”→“认证与工具发现成功”→“真实样本可取得并定位”→“错误与时效路径验证”→“律师认可该任务输出”，逐级记录。本报告和[providers.json](../config/providers.json)仅达到公开文档核查层面；用户确认的是北大法宝官方服务身份，尚不是本环境连接成功。
