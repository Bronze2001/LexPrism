## 本次吸收与修正

| 模板内容 | 指引中的处理 |
| --- | --- |
| 委托与事项、事实、依据、请求、结尾与落款 | 吸收段落功能及顺序，按本次发函目的调整，不固定请求数量或必须列法条 |
| 律所名称、函号简称、页眉地址、网站和标识 | 通用底稿留空，委托开头与落款同步处理；不沿用样本身份、署名或签署状态 |
| 收函后 7 日回复 | 不设为默认天数；分别判断履行与回复期限、起算事件和依据 |
| 已构成违约、已导致损失、全部后果由对方承担 | 分项匹配事实、依据、条件及委托范围，不因模板有该句就使用 |
| 委托人已承诺材料真实、完整、准确 | 只有确有承诺时才写；事实来源说明与核查结果分开 |
| 权利保留、事实异议与沟通 | 保留各自用途及可用渠道，不将保留文字视为权利或法律效果的保证 |
| 批注与脱敏 | 读取批注及对应正文；如另行制作脱敏副本，检查图片、页眉页脚、作者、属性、修订、缩略图及嵌入内容 |
