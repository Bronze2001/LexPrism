# 埃及电商投资贸易主要规定合规要点

**审查事项**：客户为园区一家产品质量/体系ISO认证服务企业，已在 noon 平台（埃及站）注册，拟为入驻电商企业提供埃及配套服务（公司注册代办、税务、产品进驻合规等）
**目标市场**：阿拉伯埃及共和国
**审查领域**：市场准入与投资 / 平台经营资质 / 税务 / 个人信息与数据 / 产品准入认证 / 消费者保护与广告 / 中国侧出境合规
**审查日期**：2026-09-18
**信息来源**：基于联网检索的国际律所与税务机构公开资料（Clyde & Co、EY、Andersen Egypt、Mondaq、noon 官方卖家中心等），埃及本土法规原文尚未逐条核对，重要事项请以埃及官方文本为准

---

## 一、总体结论

1. **埃及没有专门的"电商平台牌照"**，也没有一部单独的"电子商务法"。电商活动散落在《电子签名法》（第15/2004号）、《消费者保护法》（第181/2018号）、《网络犯罪法》（第175/2018号）、《电信监管法》（第10/2003号）、《个人数据保护法》（第151/2020号）及税务征管体系中。经营本身靠**商业登记 + 税务登记**支撑，特定环节（支付、电信、数据）另需专门许可。
2. **客户自己的定位是"服务商"而非卖货方**，核心风险点不在产品清关，而在三件事：① 在埃及有没有合法经营主体（noon 埃及站对卖家的硬性要求是**本地注册公司 + 税务卡 Tax Card**，服务商大概率同理）；② 数据合规（将处理大量入驻商户及个人信息，埃及 PDPL 已于 2025-11-01 进入实施期，**2026-10-31 全面执法**，窗口期只剩约 1 个月）；③ **自身出具认证文件的资质边界**——ISO 认证/检测结论若面向埃及市场使用，须由经埃及认可机构（EGAC）或国际互认（IAF/ILAC）体系认可的机构出具，否则文件效力会被海关、GOEIC 或客户质疑。
3. **客户端（入驻电商卖家）的核心门槛**是：本地公司或个体登记、税务卡、VAT 登记、电子发票/电子收据系统、进口场景下的 GOEIC 注册与装运前符合性认证（COI/CoC）。这些正是客户要"代办"的内容，代办本身需注意**税务代理、报关报检类业务在埃及可能属于持牌服务**（海关代理须经海关总署注册），不能笼统包办。

## 二、逐领域要点

### 领域一：市场准入与投资设立（GAFI 框架）

| 事项 | 要点 |
|------|------|
| 法律基础 | 2017年第72号《投资法》及实施细则，主管机构为投资与自由区总局（GAFI），实行一站式服务 |
| 外资持股 | 外国投资者一般可 **100% 独资**，无最低/最高投资额限制（普通自由区项目）；**例外：西奈半岛项目除外** |
| 常见形式 | 内地公司（LLC 最常见，至少 2 名股东——*股东人数等细节待按最新《公司法》核实*）、分公司、代表处（不得直接经营）、自由区公司 |
| 自由区（Free Zone） | 进出口免关税、项目利润免国内所得税，但**原则上要求出口导向**，做本地服务业务不适合；私营自由区门槛极高（发行资本≥1000万美元、投资≥2000万美元、面积≥2万㎡） |
| 设立流程 | 初步批准 → 外国合伙人安全审查 → 缴费 → 章程公证注册 → 商业登记 → 税务卡 → 社保登记；通常数周至数月 |
| 外籍员工 | 需工作许可；外籍/本地员工比例有限制（通常 1:9 或按实缴资本折算——*具体比例待核实*） |

> 对客户：若要在埃及实地提供注册代办、税务咨询、认证辅导，建议设立**内地 LLC 或与埃及持牌机构合作**；代表处不能收费经营。同时中国侧需完成**发改委/商务部门境外投资备案（ODI）+ 外汇登记**，这是客户自己的合规前置。

### 领域二：平台经营与资质

| 事项 | 要点 |
|------|------|
| 电商专项牌照 | 无统一"e-commerce license"；自建支付/收单须**埃及中央银行（CBE）牌照**，单纯依托 noon 平台收款则不涉及 |
| noon 埃及站要求 | 卖家须**公司注册在埃及**（国际卖家模式在埃及站官方标注 not applicable）；必备文件：商业登记（CR）、**税务卡（Tax Card，强制）**、以公司名义开立的银行账户、法人/业务代表身份证件、品牌授权或采购凭证；文件有效期须剩余至少 30 天 |
| 广告宣传 | 《消费者保护法》181/2018 及广告相关法规禁止误导性宣传；认证服务宣传中"最权威""包过""官方指定"等用语有风险 |
| 中介行为 | 代办公司注册、税务申报、海关报关等属**受监管的代理服务**：税务代理须符合税务部门要求，海关报关行（customs clearance agent）须在海关总署注册。客户若自己做需要资质，更稳妥的模式是"自己出合规方案 + 本地持牌机构执行" |

### 领域三：税务（客户及其服务的卖家都绕不开）

| 事项 | 要点 |
|------|------|
| 所得税 | 公司所得税一般税率 22.5%（特定行业更高）；服务费可能涉及源泉扣缴 |
| 增值税 VAT | 标准税率 **14%**（2016年第67号增值税法）；提供认证咨询服务同样属于应税服务 |
| VAT 登记门槛 | 有法定营业额门槛（约 EGP 50 万/年，货物与服务门槛不同——*具体数额待核实*）；平台卖家实践中通常被要求提供税号 |
| 电子发票（B2B/B2G） | 依据2020年第206号《统一税务程序法》，**所有 VAT 登记企业强制**，须在 ETA 门户注册、接入系统清分；2023年7月起纸质发票不能抵扣进项税 |
| 电子收据（B2C） | 独立系统，按批次强制纳入；2026年1月起进入执法阶段（罚款、二维码强制）；2026-03-31 起注册门槛降至 EGP 25 万 |
| 罚则 | 逾期未注册：EGP 2 万 + 每日 EGP 1,000；虚假单据最高 EGP 5 万并可能监禁；年营业额 ≤EGP 2,000 万的企业须活跃使用电子票证才能享受简化税制（2025年第6号法） |
| 2025年新政 | 2025-10-23 部长令第417/418号修订 VAT 实施细则（进项抵扣扩大、建筑合同过渡规则），**未直接涉及电商平台代扣代缴**；平台与卖家之间的税务口径以 ETA 后续通告为准 |

> 对客户：这是它给卖家做"税务配套服务"的核心知识面。注意埃及电子发票/收据是**两套独立系统**，帮客户接入时不能只做一套。客户自身收费也须开 Egyptian e-invoice（如已做 VAT 登记）。

### 领域四：个人信息与数据（合规时间最紧的一块）

| 事项 | 要点 |
|------|------|
| 法律 | 《个人数据保护法》第151/2020号；**实施条例 2025-11-01 生效**，主管机构为个人数据保护中心（PDPC） |
| 登记/许可 | 数据控制者与处理者须向 PDPC 取得**许可或登记**；任命并登记 DPO（数据保护官）；跨境传输、直接电子营销、公共场所 CCTV 另需专项许可；小型数据库可豁免费用 |
| 跨境传输 | 须 ①PDPC 批准 + ②数据主体同意 + ③限经批准的目的国。**客户若把埃及商户/用户数据传回中国处理，双向都触发合规**：埃及侧要走 PDPC 批准，中国侧按《个保法》走出境路径（标准合同/安全评估等） |
| 泄露通知 | 72 小时内报 PDPC，3 个工作日内通知受影响个人 |
| 处罚 | EGP 20 万–500 万罚款，特定情形刑事责任，违规强制公开 |
| 时间线 | 12 个月宽限期，**2026-10-31 全面执法** |

> 对客户：**这是当前 P0 事项**。建议立即盘点数据流（商户资料、联系人信息、认证审核材料），确定是否做 PDPC 登记、是否设 DPO，并在与 noon 及商户的合同中加入数据处理条款。

### 领域五：产品准入与认证（客户的主业，须讲清"谁有资格出证"）

| 事项 | 要点 |
|------|------|
| 主管机构 | 出口与进口控制总局（**GOEIC**，隶属贸工部）负责进口管制与注册；埃及标准化组织（EOS）定标准；电信设备归 **NTRA**；食品药品归 EDA |
| 外国工厂注册 | 输埃产品的外国工厂/品牌须在 GOEIC **注册名单**（源自主管部门第43/2016号决定，注册通常凭 ISO 体系证书+测试报告等，*最新执行口径待核实*） |
| 装运前认证 | 多数消费品、机电产品进口须**符合性证书（CoC/COI）**，通过装运前检验获得；GOEIC 还管进口商注册（进口商卡） |
| 电信/无线设备 | 含蓝牙、Wi-Fi、蜂窝模块的产品须 NTRA 型式认可 |
| 食品/化妆品/医疗器械 | 分别向 EDA 等主管部门注册，肉类清真认证由伊斯兰事务最高理事会等监管 |
| **客户资质边界** | 出具 ISO 管理体系认证须由 **EGAC（埃及认可委员会）或 IAF 成员认可**的认证机构实施；客户若自身不是获认可 CB，应定位为"咨询/辅导/代办送检"而非"发证"，避免无资质出证引发法律与商誉风险 |

### 领域六：消费者保护与广告

- 《消费者保护法》181/2018：商品信息真实、价格透明、特定条件下退换货；设消费者保护局（CPA）受理投诉，对服务商宣传同样适用。
- 《网络犯罪法》175/2018 与《反洗钱/反恐融资》框架：平台生态下的电子欺诈、数据盗用有刑事后果；为商户服务时注意 KYC 留痕。

## 四、需进一步核实事项（本次未能验证，不做结论）

1. VAT 登记门槛的现行准确数额（货物与服务是否区分）及平台代扣代缴义务是否有新规。
2. GOEIC 外国工厂注册（43/2016号决定）的最新执行细则与证书有效期。
3. 埃及《公司法》下 LLC 最低资本、股东人数现行要求；外籍员工比例现行标准。
4. PDPC 登记/许可的实际开放情况（机构运营进度，公开资料截至 2026 年初未完全明确）。
5. 税务代理、报关代理持牌的具体条件。
6. noon 对"服务商类"账户（非卖货）是否有单独入驻通道及要求。

以上建议在正式出具服务方案前，通过埃及本地律师/税务师或 GAFI、ETA、GOEIC 官方渠道逐项确认。

## 五、风险提示

- 本报告为一般法律信息梳理，不构成正式法律意见，不替代埃及执业律师/税务师意见。
- 埃及处于立法活跃期（数据保护实施条例 2025 年末刚落地、电子收据 2026 年进入执法、VAT 细则 2025 年 10 月刚修订），**引用的任何规定在执行前都应二次核实时效状态**。
- 客户最大的两个实质性风险：①数据跨境（中埃双向）未办手续即开展业务；②以"认证机构"名义出具无认可背书的证书。
