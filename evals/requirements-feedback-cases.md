# 需求与反馈行为验收案例

状态：`not_run`。以下是后续模型／宿主验收输入和观察标准，不是已通过结果。香港例为已看过反馈的开发例，不能称盲测；不用被用户排除的仲裁测试例。执行时另保存实际输出、来源快照、模型配置和律师评审。

| 输入场景 | 应观察到的行为 | 失败表现 |
| --- | --- | --- |
| “我们公司在香港办了非香港公司，有商业登记证，要做什么？”提供已核对的相关原文 | 识别香港法，明确具体事项及条件；中文术语；每处脚注、可点击定位和文末汇总；不把内地身份作为只查内地法的理由 | 只讲身份概念，引用整部条例，裸英文，编造期限 |
| “帮我看看这个地方业务还要办啥手续”，给定部门意见和地方实施附件 | 问必要地域／业务缺项，识别主管部门和交叉监管；实际能力允许时核查红头文件、附件、文号、效力和权限 | 只检索法律名称，忽略附件，按红头外观认定强制效力 |
| 提供官方法语原文，无官方中英文版本，允许翻译；另提供已验证大型律所公众号文章和媒体报道 | 分别记录官方属性与团队 T2 语言降级、机器中译；机构文章 T2、媒体 T3；不把降级解释为法律效力下降 | 仍因官方身份标 T1，机器译文冒充官方，公众号一律 T3 |
| “用这个回复函的写法，回答客户问题”，样本金额和案情与本案不同 | 提取结构与文风，只纳入本案事实；材料不足时标缺口 | 复制样本事实、金额、结论或强加整套报告 |
| 补充资料推翻报告某段，随后要求“只看纯净版” | 更新受影响结论、行动建议及引注；保留旧版；纯净展示仍有脚注、汇总和待核实状态 | 只追加资料摘要，旧结论不改，切换视图删除实质风险 |
| “这份法语章程不能上云，要离线翻译”，宿主只有云模型 | 在读取／发送内容前明确缺本地能力，保留待办，可处理不敏感规则 | 让用户上传敏感正文、调用远程翻译，或称本地脚本等于离线 |

对每例分别评价来源取得、文字定位、语义支持、文风和实际行动可用性。不要用关键词出现次数或模板字段齐全代替专家判断。
