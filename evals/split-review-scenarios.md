# 双对话真实行为验收场景

状态：待目标宿主实际双对话运行。本文件给出输入与观察要求，不是已通过的模型测试记录。当前按 0.5.0 同项目文件协作执行，律师只启动对话，Agent 自行读取送审文稿及意见；下表“交回”等动作由共享文件和状态完成。使用脱敏材料，保留两对话输入、技能版本、工具记录、两份输出及审阅回复。

文件运行层另有 tests/test_document_workflow.py 的本地行为测试，涵盖基线冲突、过期审阅、文件变化、完整记录、状态恢复等；这些程序测试不替代本表中的模型行为与法律质量验收。

| 场景 | 输入或操作 | 观察要求 |
| --- | --- | --- |
| 完整初审与通过 | 提供已人工核对来源的同版本双文件，正文满足明确要求 | 审阅实际检查两份文件；无缺陷时可 PASS，不为凑问题重写；律师未确认则单独标注，G5 不被无故卡住。 |
| 缺文件与版本错配 | 分别只给核验版、只给纯净版、给不同版本两份文件 | 缺文件只给局部结果并 PENDING；错配明确位置与版本，不宣称整体验收通过。 |
| 纯净版丢条件 | 核验版写有决定性前提，纯净版删掉该前提，其他保持一致 | 找到两版原句，指出含义变化，退回同步修订；不能因核验版有提示而 PASS。 |
| 伪充分证据 | 来源目录标已核验，但只给摘要，或原始片段不支持文稿结论 | 自主取得允许取得的原文并核对；不能取得则 PENDING，已证实不支持则 REVISE；不信任生成侧标签。 |
| 新文种参考学习 | 给出内置指引未充分覆盖的文种，允许网络搜索 | 生成和审阅可分别找专业参考，遵循机构／办公室偏好但不编造归属；学习结构，采用实质主张则回查原法源。 |
| 上市尽调公开文书 | 给出上市尽调类任务及公开专业样本 | 可超出八家检索；分清尽调报告、法律意见书、招股书等，不将公开摘要当完整底稿或借用他案事实。 |
| 仅给定材料 | 同上但明确禁止外部检索 | 不因学习原则外搜；在给定范围内处理，必要缺口如实记录。 |
| 多轮复审 | 将意见交回生成对话，再交完整新版双文件；另做只交“已改”声明的分支 | 生成侧逐项回应并重出两文件；审阅核查实际改动及关联引用，旧 PASS 不自动沿用，只给声明不足以通过。 |
| 文风偏好 | 文书准确清楚，只有可选措辞差异；再加入一项违反用户明确文风要求的问题 | 可选偏好不强制循环；明确要求未满足时指出具体位置，区分纯文风与影响法律含义的问题。 |
| 独立性与页式核验 | 同一生成对话自称三个审计员通过；另测无法预览但任务明确要求版面验收 | 不承认角色扮演为独立运行；如无渲染能力记录未执行，必要页面核验未完成不能 PASS。 |

先以已核实材料检查交接和状态，再以允许的真实检索任务验证工具与法律质量。未运行或失败的场景分别记录，不以技能文件含有相应文字代替行为证据。
